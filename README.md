# Калькулятор калорий
## Описание проекта

Программа представляет собой калькулятор калорий, разработанный на языке Python.

Калькулятор определяет ориентировочную суточную потребность организма в калориях на основе индивидуальных параметров пользователя.

## Возможности программы
- Расчёт базового обмена веществ (BMR).
- Расчёт суточного расхода энергии (TDEE).
- Расчёт калорий для поддержания веса.
- Расчёт ориентировочной нормы калорий для похудения и набора веса.
- Расчёт суточной нормы белков, жиров и углеводов.
## Используемые технологии
- Python 3
- Google Colab
- GitHub
## Метод расчёта
Для расчёта базового обмена веществ используется формула Миффлина — Сан Жеора.
